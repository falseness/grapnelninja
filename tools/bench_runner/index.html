Grapnel Ninja offline benchmark

Local serving only. This page and the game load nothing from the internet and send results only to the machine serving this page.

Open the game with the benchmark panel (landscape on phones; the panel sits at the bottom of the game).

Preset links: Main version · Chill version · manual replay

Steps

  1. Fill in the actual device model, the display refresh rate (or unknown), DevTools state, CPU throttle and emulation (none on a real device).
  2. Select the mode, tap Start run, keep the screen on and do not touch the game: 5 s warmup then 60 s of measured active play with the seeded synthetic throws (or play the documented script with manual replay).
  3. Repeat until 3 complete runs per mode. Results are sent to the serving machine after every run; Download results keeps a copy on the device.
